# Workflow Agêntico

Este modo preserva a Engenharia de Loops do Code Discovery Toolkit para repositórios grandes e agentes com capacidade de operar iterativamente.

## Componentes

- `AGENTS-discovery-template.md`: regras de comportamento, escopo e segurança.
- `engenharia-de-loops-guia.md`: varredura módulo a módulo, verificação cruzada, MCP, Approval Gates e Guardião de Validação Humana.

A Engenharia de Loops continua sendo um workflow próprio. Ela pode consumir os prompts do modo manual e, futuramente, evidências do modo determinístico, sem acoplar essas estratégias à lógica do loop.

> Nesta reorganização a lógica dos loops foi preservada. O objetivo foi tornar sua fronteira arquitetural explícita, não redesenhá-la.
